# Вариант 6 — этап 1 (Kotlin)

CLI-приложение загружает пользовательские настройки из XML-файла,
проверяет каждый параметр и выводит настройки в формате `ключ = значение`.

## Настройки

- `package` — имя анализируемого пакета.
- `repository` — URL репозитория (HTTP/HTTPS) или путь к файлу тестового репозитория.
- `testMode` — `true` для тестового режима или `false` для обычного режима.

## Запуск

Требуется установленный Kotlin compiler (`kotlinc`) и JDK.

```bash
chmod +x run.sh
./run.sh
```

По умолчанию используется `config.xml`. Можно передать другой файл:

```bash
./run.sh config-test.xml
```

## Проверка

`config.xml` демонстрирует обычный режим, `config-test.xml` — тестовый режим.
Для проверки ошибок можно изменить значение любого XML-параметра:
удалить тег, продублировать его, оставить пустым или указать неверное значение.

## Структура

- `src/main/kotlin/Main.kt` — исходный код приложения.
- `config.xml` — основная конфигурация.
- `config-test.xml` — конфигурация тестового режима.
- `tests/Cargo.toml` — тестовый файл репозитория.
- `run.sh` — сборка и запуск.

## Этап 2. Получение зависимостей Cargo

На втором этапе реализовано получение прямых зависимостей пакета в формате Rust Cargo.

### Реализованные возможности

- Получение информации о пакете из репозитория.
- Определение последней версии пакета.
- Получение списка зависимостей через API репозитория.
- Чтение зависимостей из локального файла `Cargo.toml` в тестовом режиме.
- Вывод найденных зависимостей в консоль.
- Обработка ошибок при получении данных и чтении файла.

### Режимы работы

**Обычный режим**

Программа обращается к репозиторию по URL, указанному в `config.xml`, получает информацию о версии пакета и запрашивает его зависимости.

**Тестовый режим**

Программа использует локальный файл `Cargo.toml`, путь к которому указан в `config-test.xml`.

### Запуск

Для тестового режима:

```bash
./run.sh config-test.xml
```

Для обычного режима:

```bash
./run.sh config.xml
```

### Структура проекта

- `src/main/kotlin/Main.kt` — основная логика приложения.
- `config.xml` — настройки обычного режима.
- `config-test.xml` — настройки тестового режима.
- `tests/Cargo.toml` — локальный файл с тестовыми зависимостями.
- `run.sh` — скрипт запуска приложения.

### Ограничения реализации

Для получения данных используется HTTP-запрос к API репозитория. Сторонние библиотеки и менеджеры пакетов для получения зависимостей не используются.
