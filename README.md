# Вариант 6 — этап 1 (Kotlin)

CLI-приложение загружает пользовательские настройки из XML-файла,
проверяет каждый параметр и выводит настройки в формате `ключ = значение`.

## Настройки

- `package` — имя анализируемого пакета.
- `repository` — URL репозитория (HTTP/HTTPS) или путь к файлу тестового репозитория.
- `testMode` — `true` для тестового режима или `false` для обычного режима.

## Запуск

Требуется установленный Kotlin compiler (`kotlinc`) и JDK.

```bash
chmod +x run.sh
./run.sh
```

По умолчанию используется `config.xml`. Можно передать другой файл:

```bash
./run.sh config-test.xml
```

## Проверка

`config.xml` демонстрирует обычный режим, `config-test.xml` — тестовый режим.
Для проверки ошибок можно изменить значение любого XML-параметра:
удалить тег, продублировать его, оставить пустым или указать неверное значение.

## Структура

- `src/main/kotlin/Main.kt` — исходный код приложения.
- `config.xml` — основная конфигурация.
- `config-test.xml` — конфигурация тестового режима.
- `tests/Cargo.toml` — тестовый файл репозитория.
- `run.sh` — сборка и запуск.
